About

Engineer first. Co-founder second.

I build software end to end. That means the Next.js front end a user actually touches, the Node, Python or PHP services behind it, the PostgreSQL schema underneath, and the AWS or Netlify pipeline that puts it all live.

My work spans brand websites and mobile apps, church digital infrastructure, Shopify-backed e-commerce, CRM and payment integrations, and global community platforms. The common thread is that these are real systems with real users — not demos.

I care about the unglamorous parts: deployment, uptime, integrations that don't silently break, and automation that removes manual work instead of adding to it.
